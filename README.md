> # MINI Project Ⅰ 설명
> <b> • 개발 기간 | 2025.02.07 ~ 2025.02.10</b> <br>
> ### [개요]
> 네이버 클라우드 네이티브 17기 부트캠프 중 진행한 개인 프로젝트
> ### [회원형 자유 게시판 시스템]
> <b> 간단한 자유게시판을 제공합니다. </b>
> 1.  회원가입&로그인
> 2.  기본 게시글
>     > 비회원 : 게시글 조회<br>
>     > 회원   : 게시글 생성&수정<br>
>     > 관리자 : 태그 등록, 게시글 삭제
> 3.  비밀글 기능
> 4.  댓글 & 답글
> <p>&nbsp;</p>

### 🔍 Description

- **Java** | 백엔드 로직
- **JSP / Tomcat |  서버 사이드 렌더링 동적 웹페이지 생성
- **HTML, CSS, JS, jQuery, Bootstrap5** | UI 구성 및 사용자 인터랙션 처리, Ajax를 통한 비동기 통신
- **MySQL / JDBC / NCP** | 사용자 및 게시글 등 주요 데이터 저장 & DAO 방식의 CRUD 통신
